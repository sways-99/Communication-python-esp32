# Communication python-esp32

This is a simple set of programs to turn on leds wuth communication python-esp32

How it works
- A python program with the Tkinter library reads the interaction with the person.
- The program sends charcter through the serail port.
- ESP32 receives the characters.
- The esp32 turn on or turn off the leds depending the pressed button.

Components
- Esp-wroom-32
- 1 protoboard
- 3 leds (red, blue and green)
- cables
